## 2. Теоретическая справка

### 2.1. Постановка задачи

Требуется найти глобальный минимум функции W(x) на отрезке [a, b]:

$$
x^* = \arg\min_{x \in [a, b]} W(x)
$$

### 2.2. Константа Липшица

Функция $$ W(x) $$ называется **липшицевой** на отрезке [a, b], если существует такая константа L >= 0, что:

$$
|W(x_1) - W(x_2)| \le L |x_1 - x_2|
$$

Наименьшая такая константа называется **константой Липшица**:

$$
L = \sup_{x_1 \ne x_2} \frac{|W(x_1) - W(x_2)|}{|x_1 - x_2|}
$$

Для дифференцируемых функций $$ L = \sup_{x \in [a, b]} |W'(x)| $$.

### 2.3. Идея метода Пиявского

Метод основан на построении **минорант** — вспомогательных функций, которые гарантированно лежат ниже графика исходной функции. Для каждой известной точки u_i строится конус:

$$
p_i(x) = W(u_i) - L |x - u_i|
$$

Верхняя огибающая всех минорант:

$$
p(x) = \max_i \left( W(u_i) - L |x - u_i| \right)
$$

даёт кусочно-линейную нижнюю оценку функции W(x). Точка минимума этой огибающей выбирается как следующая точка для вычисления функции. Итерационный процесс продолжается до выполнения условия:

$$
W_{\text{best}} - p_{\min} < \varepsilon
$$

где $$ W_{\text{best}} $$ — лучшее найденное значение функции, $$ p_{\min} $$ — минимум миноранты.

## 3. Реализация

### 3.1. Структура программы

Программа состоит из следующих модулей:

- `f(x, expression)` — вычисление значения функции по строковому выражению;
- `estimate_lipschitz(expression, a, b)` — численная оценка константы Липшица;
- `minorant(x, x_points, y_points, L)` — вычисление значения миноранты в точке;
- `find_minorant_minimum(...)` — поиск точки минимума миноранты;
- `piyavskiy_method(...)` — основной итерационный процесс.

### 3.2. Оценка константы Липшица

Константа Липшица оценивается численно по сетке из 10000 точек:

```python
def estimate_lipschitz(expression, a, b):
    x = np.linspace(a, b, 10000)
    y = np.array([f(value, expression) for value in x])
    slopes = np.abs(np.diff(y) / np.diff(x))
    L = 1.1 * np.max(slopes)  # запас 10% для надёжности
    return max(L, 1e-10)
```

Множитель `1.1` вводит небольшой запас, чтобы оценка не оказалась меньше истинной константы Липшица (иначе миноранты перестанут быть минорантами).

### 3.3. Поиск минимума миноранты

Точка пересечения двух соседних минорант вычисляется аналитически:

```python
x_cross = (y1 - y2) / (2 * L) + (x1 + x2) / 2
```

Далее среди всех кандидатов (известные точки + точки пересечения) выбирается та, где миноранта минимальна.

### 3.4. Основной цикл

```python
while True:
    x_new, p_min = find_minorant_minimum(x_points, y_points, L, a, b)
    best_y = min(y_points)
    if best_y - p_min < eps:
        break
    y_new = f(x_new, expression)
    x_points.append(x_new)
    y_points.append(y_new)
```

## 5. Выводы по методу

1. **Скорость сходимости.** Метод Пиявского сходится за конечное число итераций, причём для гладких функций число итераций меньше, чем для «зубчатых».

2. **Зависимость от \(L\).** Чем точнее оценена константа Липшица, тем быстрее сходимость. Завышенная \(L\) замедляет метод, заниженная — делает результаты недостоверными.

3. **Устойчивость к локальным минимумам.** В отличие от градиентных методов, метод Пиявского находит именно **глобальный** минимум, так как миноранты «накрывают» всю функцию целиком.

4. **Ограничения.** Метод плохо работает при больших \(L\) (много итераций) и при наличии разрывов у функции.
