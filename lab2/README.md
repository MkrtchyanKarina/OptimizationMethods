# Отчёт по лабораторной работе: метод Пиявского для поиска глобального минимума функции

## 1. Цель работы

Изучить и реализовать метод Пиявского для приближённого поиска глобального минимума одномерной функции на заданном отрезке. Проверить работу программы на тестовых функциях, вывести результаты вычислений и построить график найденного решения.

## 2. Теоретическая справка

### 2.1. Постановка задачи

Требуется найти глобальный минимум функции $f(x)$ на отрезке $[a,b]$:

$$
x^* = \arg\min_{x \in [a,b]} f(x).
$$

Метод Пиявского использует информацию о значениях функции в уже исследованных точках и оценку её константы Липшица.

### 2.2. Константа Липшица

Функция $f(x)$ называется липшицевой на отрезке [a,b], если существует число $L \geq 0$, для которого выполняется:

$$
|f(x_1)-f(x_2)| \leq L|x_1-x_2|
$$

для любых $x_1,x_2 \in [a,b]$.

Константа Липшица ограничивает скорость изменения функции. В программе её значение оценивается численно по равномерной сетке: вычисляются значения функции в соседних узлах, находятся модули разностных отношений, после чего максимальное значение увеличивается на небольшой коэффициент запаса.

**Важно:** такая процедура даёт численную оценку $L$, но сама по себе не доказывает, что полученное число не меньше истинной константы Липшица на всём отрезке. Поэтому гарантия глобальной точности метода зависит от достаточности выбранной оценки $L$.

### 2.3. Миноранты и нижняя огибающая

Для каждой исследованной точки $x_i$, в которой известно значение $f(x_i)$, строится функция:

$$
p_i(x)=f(x_i)-L|x-x_i|.
$$

Если $L$ действительно является константой Липшица, то каждая такая функция лежит не выше исходной функции. Верхняя огибающая этих функций образует нижнюю оценку:

$$
p(x)=\max_i\left(f(x_i)-L|x-x_i|\right).
$$

Алгоритм использует нижнюю огибающую, чтобы определить участки, в которых ещё может находиться минимум. На очередной итерации выбирается новая точка, в ней вычисляется значение исходной функции, а результат добавляется к уже известным данным.

Критерий остановки основан на разности между лучшим найденным значением и нижней оценкой минимума:

$$
f_{\text{best}}-p_{\min}\leq\varepsilon,
$$

где $\varepsilon$ — заданная точность. Также выполнение алгоритма ограничивается максимальным числом итераций, чтобы избежать бесконечного цикла.

## 3. Реализация программы

### 3.1. Ввод функции

Пользователь задаёт функцию в виде строкового математического выражения, границы отрезка $a$ и $b$, точность $\varepsilon$, а также имена файлов для отчёта и графика.

Для вычисления выражения разрешены только поддерживаемые математические операции, переменная `x`, число `pi` и функции из заданного списка. Перед вычислением выражение проверяется с помощью AST: неподдерживаемые конструкции и неизвестные имена отклоняются. При вычислении также обрабатываются распространённые ошибки и проверяется конечность результата.

Примеры выражений:

```python
sin(x) + x**2
exp(x) - 3*cos(2*x)
sqrt(x**2 + 1)
```

Операция возведения в степень может вводиться как `**`; при вводе символ `^` преобразуется в `**`, если это предусмотрено текущей версией программы.

### 3.2. Оценка константы Липшица

Для оценки $L$ функция вычисляется в узлах равномерной сетки на отрезке $[a,b]$. Затем определяется наибольший модуль разностного отношения соседних значений. Полученная оценка умножается на коэффициент запаса; для предотвращения нулевого значения применяется минимальная положительная граница.

Такая оценка является приближённой. Увеличение коэффициента запаса не гарантирует, что $L$ будет верхней границей для всех точек отрезка, особенно если функция быстро меняется между узлами сетки.

### 3.3. Основной алгоритм

На начальном этапе вычисляются значения функции на границах отрезка. Затем алгоритм повторяет следующие действия:

1. Упорядочивает исследованные точки по координате $x$.
2. Строит локальные оценки на соседних интервалах и определяет кандидатов для следующего вычисления.
3. Вычисляет нижнюю оценку возможного минимума и разность между ней и лучшим найденным значением.
4. Если разность не превышает $\varepsilon$, завершает поиск.
5. Иначе вычисляет исходную функцию в выбранной новой точке и обновляет лучший найденный результат.
6. Завершает работу, если достигнуто максимальное число итераций.

Результат содержит найденную точку минимума, значение функции в ней, количество итераций, затраченное время, использованную оценку $L$ и таблицу изменения оценок по итерациям.

### 3.4. Построение графика

График включает:
- исходную функцию на исследуемом отрезке;
- нижнюю огибающую, построенную по исследованным точкам;
- точки, в которых вычислялась функция;
- найденный приближённый минимум.

## 5. Анализ результатов

При анализе каждого запуска следует обратить внимание на следующие показатели:

1. **Найденный минимум.** Координата \(x_{\min}\) и значение \(f(x_{\min})\) показывают лучший из найденных результатов.
2. **Число итераций.** Зависит от функции, выбранной точности, отрезка и оценки константы Липшица.
3. **Время вычислений.** Позволяет сравнивать длительность запусков при одинаковых условиях.
4. **Разность оценок.** Уменьшение разности между лучшим найденным значением и нижней оценкой свидетельствует о приближении к критерию остановки.
5. **Влияние \(L\).** Слишком большая оценка \(L\) обычно делает нижние конусы более крутыми и может увеличивать число итераций. Если оценка занижена, нижняя огибающая может перестать быть корректной.

Результаты запусков и конкретные значения показателей следует интерпретировать по полученным консольным данным, графикам и таблицам итераций.

## 6. Ограничения метода

- Корректность нижних оценок зависит от того, является ли выбранное \(L\) достаточной верхней границей константы Липшица.
- Численная оценка $L$ по сетке не даёт строгой гарантии, что функция не изменяется быстрее между узлами.
- При слишком большой оценке \(L\) поиск может потребовать много итераций.
- Функция должна быть определена и иметь конечные значения на исследуемом отрезке; выражения с недопустимыми аргументами могут привести к ошибке вычисления.
- Достижение максимального числа итераций не означает, что заданная точность обязательно достигнута.

Программа позволяет вводить математическое выражение и параметры поиска, вычислять приближённую константу Липшица, выполнять итерационный поиск, строить график и сохранять результаты в текстовый файл.

Метод использует нижние оценки функции для выбора следующих точек исследования и критерий остановки, основанный на разности между лучшим найденным значением и нижней оценкой минимума. При этом достоверность глобальной гарантии зависит от корректности оценки константы Липшица: численная оценка по сетке сама по себе такой гарантии не обеспечивает.
